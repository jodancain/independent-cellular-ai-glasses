# 芯片候选与选择依据

**v0.1 公开讨论稿 · 来源核验日期 2026-11-02**

推荐顺序是本项目的工程判断，不是厂商对智能眼镜适用性的认证。优先让供应商对 W527、W5 系列加蜂窝及其成熟替代方案提交同负载整机数据，不提前锁定单一芯片。

## 配置与证据边界

- 芯片能力、开发板实例和最终眼镜是三个层级。板上 2GB 或 4GB 既不等于芯片容量上限，也不证明供应商能在目标功耗和结构中交付同等配置。
- W527 的 4GB 加 32GB、Android 的 4GB 加 32–64GB 都只是询价候选，不是已验证的统一量产配置。
- 参考板标注的 eSIM 预留不能写成整机已实现；蜂窝必须同时确认 modem、射频、天线、卡方案、运营商和认证。
- RV1126B 的公开典型功耗项仍为 TBD，不能用旧 RV1126 的数值代替。
- ESP32 系列不满足本项目 ARM 应用主核方向，可作为局部连接或控制参考，不进入主处理器优先名单。
- 任何方案仍需验证目标眼镜上的持续蜂窝上行、音视频、显示并发、功耗、热和资源趋势。

## 供应商补充证据

每条路线请补充可采购型号与版本、RAM/存储选项、媒体和显示能力、系统及 BSP 交付范围、第三方许可、供货及维护状态，以及同口径整机测试。参数缺少证据时标注待确认，不根据相近型号或上一代平台自动补齐。
