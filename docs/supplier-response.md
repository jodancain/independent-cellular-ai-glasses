## 3 同口径测试说明

请描述可公开测试方法，不上传真实设备标识、凭据、原始客户数据或内部日志。

- 被测对象：芯片规格／开发板／目标结构样机／量产整机，待填写。
- 软硬件版本和依赖：待填写公开版本信息。
- 网络条件：制式、信号条件、移动或遮挡条件，待填写。
- 并发负载：摄像编码、音频、显示、业务计算和蜂窝传输，待填写。
- 画质参数：分辨率、实际帧率、码率和编码器配置，待填写。
- 测量条件：环境温度、持续时长、电池状态、功耗测点、温度测点，待填写。
- 输出：功耗、温升、续航、降频、丢帧、时延、音画同步、异常恢复和资源趋势，待填写。
- 当前不能满足或尚未验证的目标：待填写。
