# 独立蜂窝智能眼镜开发需求

**v0.1 公开讨论稿 · 来源核验日期 2026-11-02**

本项目整理可独立联网的智能眼镜需求，供硬件供应商、系统开发者和集成方共同评审。优先面向汽车服务场景中的现场作业与远程协作，并预留面向车主的功能路线。

目标是找到一套**脱离手机和手机热点、使用机内 SIM 或 eSIM 蜂窝网络、由 ARM 应用主处理器运行自研业务软件**的可维护方案。应用、账号和云服务由项目方自主建设，不以第三方消费级品牌的账号、AI 或云服务作为核心功能前提。

本仓库是需求、证据和方案讨论的协作入口，**不是可直接量产的硬件设计，不是性能承诺、采购订单或最终冻结规格**。具体配置、费用、认证、供货与维护责任须另行确认。

## 当前合作重点

1. 对比 W527、W5 系列蜂窝SKU及供应商已有量产经验的替代方案，不预先锁定单一芯片。
2. 对基础 HUD 文字箭头与空间 AR 分两档提案和报价，不将 6DoF 作为统一硬性要求。
3. 在相同负载下验证整机功耗、温升、续航、音视频、显示和蜂窝并发能力。
4. 确认 BSP、驱动、系统接口、权限、签名、OTA、许可和长期维护能实际交付。

## 如何公开协作

- 对需求、资料或结论有补充，可先开 Issue，说明具体问题、来源和影响。
- 供应商可复制[回复模板](docs/supplier-response.md)，通过 Pull Request 提交可公开的技术方案；也可直接提出文档修订。
- 每次修改应区分公开事实、项目判断、建议目标和待确认项。参数变化须附来源版本、测试条件或明确的待验证说明。
- Pull Request 由维护者评审后决定是否合并。提交建议不代表获得直接写入权限、方案被选用或采购承诺。
- 商业报价、合同、保密资料和个人联系方式不放入公开 Issue 或 PR，另用双方确认的非公开渠道交流。

## 公开内容边界

本仓库只维护可公开的文本需求和引用。不接收固件、SDK 二进制、解包文件、私钥、令牌、真实设备标识、内部日志或客户数据。不要上传本方内部需求文件的原始副本。

## 许可状态

本项目暂未选择仓库许可证。不要把公开可读或接受 PR 理解为已授予 MIT、Apache 或其他开源许可。引用的第三方项目和资料分别遵循其自身许可与使用条件；本仓库不改变这些条件。
